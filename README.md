# IEEE IES IPS Philippine Chapter: Open Silicon 2026 Workshop Submission - IEEE Chapter Logo

- [Read the documentation for project](docs/info.md)

## What is This Submission?

This repository contains the necessary Verilog code to simulate the IEEE logo moving across the playscreen in VGA Playground, bouncing and ricocheting off the borders of the playscreen. The logo itself is contained within an octagon, and the color of the logo can be changed by the user while the simulation runs simply by pressing _space_ and then pressing the _A_ button. Doing so will cycle through the available colors that the logo can observe.

This submission is to be fabricated along with the SKY26a open shuttle as a part of IEEE IES IPS Philippine Chapter's submission for the international Open Silicon 2026 IC Design Workshop, a joint operation between IEEE and Tiny Tapeout to provide a training seminar/workshop on the use of open-source IC design tools. Once fabricated, this design, along with others, will be showcased and demonstrated to the participants of the workshop held in the Philippines by IEEE IES IPS Philippine Chapter.
